# Support

## Where to get help

| Need | Where |
|---|---|
| Usage question | Read [README.md](README.md) ([français](README.fr.md)), then `python3 websearch.py --help` |
| Reproducible bug | [Bug report](https://github.com/TFD-42/dendropivot-search/issues/new?template=bug_report.yml) |
| A search backend stopped working | [Backend breakage](https://github.com/TFD-42/dendropivot-search/issues/new?template=backend_breakage.yml) |
| New idea | [Feature request](https://github.com/TFD-42/dendropivot-search/issues/new?template=feature_request.yml) |
| Security vulnerability | Private report, see [SECURITY.md](SECURITY.md) |

## Before opening an issue

1. Update to the latest release.
2. Re-run with `--debug --log-file websearch.log`.
3. Try `--no-ollama` to rule out the local model.
4. Remove personal data (queries, IPs, hostnames) from what you paste.

Support is provided on a best-effort basis by volunteers.
