# DendroPivot

### Локальный веб-поисковик с защитой конфиденциальности для Python — превращает один запрос в навигируемое дерево знаний

**Не требует API-ключа. Опциональный локальный Ollama LLM. Только стандартная библиотека Python.**

DendroPivot превращает единственный поисковый запрос в управляемый путь исследования. В каждом раунде исходный запрос ветвится на пять *фокусных* переформулировок и пять *смежных* тем; то, что вы читаете, укрепляет дерево, и любой результат может стать новым корнем. Работает в терминале или как живая локальная веб-страница, запрашивает несколько бесплатных поисковых индексов без API-ключа, может использовать локальную LLM через [Ollama](https://ollama.com) и требует только стандартной библиотеки Python.

## Зачем DendroPivot?

Один поисковый запрос показывает только один угол зрения на тему. DendroPivot рассматривает ваш запрос как **семя**, разворачивает его в пять переформулировок и пять смежных тем, запускает их против нескольких бесплатных поисковых индексов и использует то, что вы реально открываете, для управления следующим раундом. Результат — дерево исследования, а не плоский список из десяти ссылок.

## Методология пивота

| Шаг | Что происходит | Почему это помогает |
|---|---|---|
| 1. **Семя** | Вы вводите начальный запрос. | Устанавливает корень дерева. |
| 2. **Ветвление** | Разворачивается в 5 фокусных углов и 5 смежных тем. | Несколько перспектив вместо одного рейтинга. |
| 3. **Чтение** | Открытие результата усиливает его словарный запас. | Ваш интерес управляет следующим раундом. |
| 4. **Рост** | Новые раунды закрепляют запросы на общих терминах. | Ключевые концепции области становятся видимыми. |
| 5. **Пивот** | `f` или Shift+клик: результат становится новым корнем. | Погружение в подтему без потери контекста. |
| 6. **Назад** | История хранит каждое дерево; `b`/`n` — навигация. | Сравнение веток и возврат в любое время. |

## Возможности

- **Два столбца за раунд**: Фокус (5 переформулировок) + Смежные (5 связанных тем)
- **Непрерывное обогащение**: прочитанные результаты влияют на следующий раунд
- **Мультибэкенд-поиск**: Bing RSS, Marginalia, Yahoo, DDG Lite — с ротацией, резервированием и охлаждением
- **HTML в приоритете**: открывает живое дерево в браузере; вне терминала создаёт HTML-снимок
- **Шесть языков**: `--lang fr|en|es|it|zh|ru`
- **Опциональный Ollama**: расширение запросов через LLM и перевод по требованию
- **Только стандартная библиотека**: никакого `pip install`, работает везде с Python 3.10+

## Требования

| Компонент | Требование |
|---|---|
| Python | **3.10 или новее** |
| Сеть | Исходящий HTTPS к поисковым бэкендам |
| Ollama | Опционально, только для расширения LLM и перевода |
| Python-пакеты | Никаких |

## Установка

```bash
git clone https://github.com/TFD-42/dendropivot-search.git
cd dendropivot-search
python3 websearch.py -q "локальные языковые модели"
```

## Быстрый старт

```bash
# Живое HTML-дерево в браузере (по умолчанию при запуске в терминале)
python3 websearch.py -q "машинное обучение"

# Один раунд как JSON
python3 websearch.py -q "машинное обучение" --rounds 1 --no-ollama --json

# Двухколоночный интерфейс терминала
python3 websearch.py -q "машинное обучение" --tui
```

## Режимы вывода

| Контекст | Вывод по умолчанию | Переопределить |
|---|---|---|
| Из терминала | Живое HTML-дерево на `http://127.0.0.1:8765/` | `--tui`, `--json`, `--text` |
| Пайп/скрипт (нет TTY) | HTML-снимок в текущем каталоге | `--html-out ПУТЬ`, `--json` |

## Параметры командной строки

| Параметр | По умолчанию | Описание |
|---|---|---|
| `-q`, `--query ТЕКСТ` | запрос | Начальный запрос-семя |
| `-n`, `--limit N` | `6` | Макс. результатов на запрос |
| `--interval СЕК` | `60` | Задержка между раундами |
| `--rounds N` | `0` | Количество раундов (0 = неограниченно) |
| `--lang КОД` | авто | `fr`, `en`, `es`, `it`, `zh`, `ru` |
| `--no-ollama` | выкл. | Только эвристическое расширение |
| `--tui` | выкл. | Интерфейс терминала |
| `--json` | выкл. | JSON на stdout |
| `--text` | выкл. | Простой текст на stdout |
| `--html-out ПУТЬ` | авто | Путь к снимку |

## Поисковые бэкенды

| Бэкенд | Эндпоинт | Примечания |
|---|---|---|
| `bing-rss` | `bing.com/search?format=rss` | Структурированный RSS |
| `marginalia` | `old-search.marginalia.nu` | Независимый индекс |
| `yahoo` | `search.yahoo.com` | HTML-парсинг |
| `ddg-lite` | `lite.duckduckgo.com/lite/` | POST-запросы |

## Модель безопасности

- Только петлевой адрес (127.0.0.1); нелокальные хосты отклоняются
- Проверка заголовка `Host` (защита от DNS-перепривязки)
- `POST` требует `Content-Type: application/json` и одного источника (защита CSRF)
- Строгий CSP, без вызовов оболочки из пользовательского ввода
